Instalar no Celular / Gerar APK

Opção 1: Instalar como Web App (PWA)

No Android (Chrome):

Menu (3 pontos) > "Instalar aplicativo" ou "Adicionar à tela inicial".

No iPhone (Safari):

Botão Compartilhar > "Adicionar à Tela de Início".

Opção 2: Gerar arquivo APK
  1. Hospede este arquivo HTML na web (Netlify / GitHub / Vercel).
  2. Acesse PWABuilder.com ou WebIntoApp.com.
  3. Cole o link e baixe o APK gerado!
